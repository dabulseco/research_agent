# research_agent
Crew.ai driven agent for local LLMs via Ollama with web search using Selenium headless browser. Blogs are created using results of the research and output as .md or .html files. NOTE: only tested on Win11 so far!  Working on fixing a few minor bugs on MacOS (Mx chips).

As of Feb 3, 2026 the Mac bugs have been fixed (when search was updated). but it has not yet been tested on Win11 again.
